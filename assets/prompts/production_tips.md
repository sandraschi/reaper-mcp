# Production Tips - Reaper-MCP

## Workflow Optimization

### Keyboard Shortcuts (Essential)
```
Space: Play/Stop
R: Start/Stop Recording
M: Add Marker
Ctrl+S: Save
Alt+Enter: Project Settings
```

### Track Templates
```
Create templates for:
- Drum recording setup
- Vocal chain (comp, EQ, reverb)
- Guitar rig
- Mix bus processing
- Mastering chain
```

### Project Organization
```
Folder structure:
ProjectName/
├── Audio/
├── Renders/
├── References/
├── Notes/
└── ProjectName.rpp
```

## Production Techniques

### Layering
```
Combine multiple takes/sounds:
- Drums: Natural + samples
- Vocals: Main + doubles + harmonies
- Guitars: DI + Amp + Room mic
```

### Parallel Processing
```
- Drums: Parallel compression for punch
- Vocals: Parallel saturation for thickness
- Bass: Parallel distortion for harmonics
```

### Reference Mixing
```
Import professional tracks:
- A/B compare levels, EQ, balance
- Match perceived loudness
- Study arrangement, space usage
```

## Time-Saving Tips

### Batch Operations
```python
# Mute all tracks at once
mute_all()

# Arm multiple tracks
for track in range(1, 9):
    arm_track(track)
```

### Markers for Navigation
```
Use markers for:
- Song sections
- Edit points
- Problem areas
- Render regions
```

### Color Coding
```
Red: Drums
Orange: Bass
Yellow: Guitars
Green: Keys
Blue: Vocals
Purple: FX
```

## Quality Control

### Before Finalizing
- ✅ Check for clicks, pops, distortion
- ✅ Verify fade-ins/outs
- ✅ Remove unused tracks
- ✅ Consolidate takes
- ✅ Save multiple versions
- ✅ Export stems for backup

### File Management
- Name tracks clearly
- Date render exports
- Keep project files organized
- Backup regularly (3-2-1 rule)
